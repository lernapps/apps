Glossar

Die Begriffe dieser App, von A bis Z, jeder mit der Seite, die ihn erklärt.

gerichteter Graph

In einem gerichteten Graphen hat jede Kante eine Richtung. Man zeichnet sie als Pfeil. Ein Weg darf Pfeile nur in ihrer Richtung nutzen.

Erklärt auf der Seite Kanten mit Richtung

Graph

Ein Graph besteht aus Knoten und Kanten. Eine Kante verbindet zwei Knoten. Jeder Knoten darf mit jedem anderen verbunden sein.

Erklärt auf der Seite Vom Baum zum Graphen

Hypertext

Ein Hypertext besteht aus Seiten, die durch Links verbunden sind. Als Graph sind die Seiten Knoten und die Links Pfeile.

Erklärt auf der Seite Ein Graph aus Seiten

Kreis

Ein Kreis führt über Kanten zu seinem Startknoten zurück. Dabei nutzt er keine Kante und keinen anderen Knoten zweimal.

Erklärt auf der Seite Vom Baum zum Graphen

Linktext

Der Linktext ist das Wort, das du anklickst. Er sagt dir, wohin der Link führt.

Erklärt auf der Seite Ein Graph aus Seiten

Sackgasse

Eine Sackgasse ist eine Seite ohne Link. Wer dort ist, kommt mit keinem Klick weiter.

Erklärt auf der Seite Der Stadtführer der 7b

Startseite

Die Startseite ist die Seite, auf der man einen Hypertext zu lesen beginnt. Von ihr aus erreichst du über Links die anderen Seiten.

Erklärt auf der Seite Ein Graph aus Seiten

Verweis (Link)

Ein Verweis, auch Link genannt, ist eine Stelle auf einer Seite, die zu einer anderen Seite führt. Er steht nur auf der einen Seite.

Erklärt auf der Seite Kanten mit Richtung

Weg

Ein Weg ist eine Folge von Kanten, die aneinanderhängen. Er beginnt an einem Knoten, endet an einem Knoten und besucht keinen Knoten zweimal. Die Länge eines Weges ist die Anzahl seiner Kanten.

Erklärt auf der Seite Vom Baum zum Graphen
