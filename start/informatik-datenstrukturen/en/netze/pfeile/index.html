Arrows instead of lines

On the page before, you had edges without a direction: you can take a bus route there and back. On this page you will get to know edges with a direction. This is how you show linked pages as a graph.

link

A link is a place on a page that leads to another page. It is only on one of the two pages.

directed graph

In a directed graph, every edge has a direction. You draw it as an arrow. A path may only use arrows in their direction.

Remember

An arrow from A to B means: page A has a link to page B. A way back needs its own arrow from B to A, like between Selin and Jona.

Exercise

What does each arrow mean?

Choose the match for each entry.

Right answer: arrow from Mia to Selin – Mia's page has a link to Selin's page.; arrow from Selin to Jona – Selin's page has a link to Jona's page.; arrow from Jona to Tom – Jona's page has a link to Tom's page.

The arrow starts at the page the link is on and points to the page it leads to. Tom has no link yet.

More on it: Tim Berners-Lee: Information Management: A Proposal (1989)

The idea is older than you: in 1989, Tim Berners-Lee at the research centre CERN suggested linking notes and texts together as a network. He drew rings and arrows and called the rings nodes and the arrows links. This grew into the World Wide Web.

A network of links on the computer

Now you draw links as arrows, from a list. First tap the page the link is on, then the page it leads to. The arrow points from the first name to the second.

Exercise

Tom adds a new link. Which links would then get you from Tom's page to Jona's page? More than one is right.

  • a link from Tom to Jona right answer

    The new arrow Tom → Jona leads straight to Jona.

    Tom → Selin, then Selin → Jona. That is a path of length 2.
