Nodes, edges, paths

On this page you will learn to show networks like the bus network as a graph. You already know the tree: it has nodes and edges, and exactly one path leads from the root to each leaf. In the bus network there is no root, and some rides lead back to the start.

graph

A graph is made of nodes and edges. An edge connects two nodes. Any node may be connected to any other node.

path

A path is a sequence of edges that join up. It starts at one node, ends at a node and visits no node twice. The length of a path is the number of its edges.

Exercise

Selin rides from the station to the pool. How long is the shortest path? Give the number of edges.

Right answer: 2

Station – Market – Pool is 2 edges. The other paths are 4 edges long.

Solution

Right answer: 2

Station – Market – Pool is 2 edges. The other paths are 4 edges long.

cycle

A cycle leads along edges back to the node it started from. It uses no edge and no other node twice.

Remember

A tree is a graph in which all nodes are joined up and there is no cycle. That is why in a tree exactly one path leads to each node, and in a graph there are often several. Careful: the word graph here does not mean a chart like in maths, but a network.

A friendship network made of string

Lay out a network in class, without a computer. You need cards, a pen and a ball of wool.

  1. Everyone writes their own name on a card and holds it in front of them. The card is a node.
  2. If you are friends with someone, stretch a piece of string to that person. Each piece of string is an edge.
  3. Look for a cycle: follow the strings until you get back to the first card.

The friendship network on the computer
