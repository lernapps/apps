The room tree from Seeberg

Every node except the root hangs from exactly one node above it. That is why exactly one path leads from the root to each node, and a tree always has one edge fewer than nodes.

Exercise

How many paths lead from the root 6b to Mia in the room tree?

  • exactly one right answer

    From 6b to room 22, and from there to Mia. There is no other path.

  • two

    Mia only hangs from room 22, and room 22 only from 6b. A second path would need another edge.

  • three

    Three edges leave 6b, but only one leads to room 22 and so to Mia.

In a tree, every node hangs from exactly one node above it. That is why there is exactly one path from the root to each node.
