Where can't you go on?

Class 7b chat

Jona: Here is my draft for our town guide.

Mia: On one page I can't go any further. There isn't a single link on it!

Ms Berg: That's called a dead end. Can you find it?

dead end

A dead end is a page without a link. Anyone there cannot go on with any click.

Exercise

Which page in Jona's draft is a dead end?

  • Library right answer

    One arrow leads to the library, but none leads away. Anyone there cannot go on with any link.

  • Pool

    Two arrows lead away from the pool, to the home page and to Bus.

  • School

    An arrow leads from School to the library. So you can go on.

As a graph, a dead end is a node with no arrow leading away. Jona needs a link on the Library page, for example to the home page.

Build the town guide

Now you build the town guide yourself. On this page you create a hypertext that follows rules. Each card is a page. Choose another page at “Link to” and tap “Add link”. Next to it or below it you can see your hypertext as a graph. With “Preview” you click through it, just like the Year 5 pupils will later.

Exercise

Selin writes the text of the School page. Which words does she put the link to the Bus page on?

  • “bus map” right answer

    The link text says what is on the target page. So the Year 5 pupils know before clicking where it leads.

  • “click here”

    This only says that you can click, but not where the link leads.

  • “link”

    You can already see that it is a link from the blue, underlined text. The word does not say where it leads.

Good link text names the target of the link. Anyone who only reads the link texts can still find their way.

A picture by someone else in the town guide

Class 7b chat

Selin: For the Pool page I found a photo on the internet, at example.org/pool: “Outdoor pool in the morning” by Kim Sander, with the licence CC BY 4.0.

Ms Berg: Then a source credit belongs under the picture.

You may only use pictures and texts by others with permission or a free licence, and always with a source credit. It has four parts: title, creator, source (the page the picture is on) and licence.

Exercise

Which source credit does Selin write under the photo?

  • “Outdoor pool in the morning”, Kim Sander, example.org/pool, CC BY 4.0 right answer

    Title, creator, source and licence are all there.

  • Photo: from the internet

    The title, creator and licence are missing. “Internet” does not say which page the photo is on.

  • “Outdoor pool in the morning”, Kim Sander

    Title and creator are right, but the source and licence are missing.

A complete source credit has four parts: title, creator, source and licence. Online, it is best to link to the licence.

StructureHow you find an element
treeFrom the root downwards: there is exactly one path.
graphFollow the edges from a node and remember where you have been, or you will go round in a loop. Take the path with the fewest edges.
hypertextStart at the home page and follow the links in their direction.
