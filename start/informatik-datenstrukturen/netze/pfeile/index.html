Kommt Selin zu Mia?

Klassenchat 7b

Mia: Jetzt hat jede und jeder von uns eine eigene Seite im Schulnetz. Auf meiner gibt es einen Link zu Selins Seite!

Selin: Danke! Auf meiner Seite habe ich nur einen Link zu Jona.

Jona: Und ich verlinke Selin und Tom. Tom hat noch gar keinen Link.

Aufgabe

Selin kann von ihrer Seite über Links zu Mias Seite klicken.

Richtige Antwort: Die Aussage stimmt nicht.

Kein Pfeil zeigt auf Mia. Mia verlinkt Selin, aber kein Link führt zu Mia zurück. Ein Link gilt nur in eine Richtung.

Lösung

Pfeile statt Linien

Auf der Seite davor hattest du Kanten ohne Richtung: Eine Busstrecke fährt man hin und zurück. Auf dieser Seite lernst du Kanten mit Richtung kennen. So stellst du verlinkte Seiten als Graph dar.

Verweis (Link)

Ein Verweis, auch Link genannt, ist eine Stelle auf einer Seite, die zu einer anderen Seite führt. Er steht nur auf der einen Seite.

gerichteter Graph

In einem gerichteten Graphen hat jede Kante eine Richtung. Man zeichnet sie als Pfeil. Ein Weg darf Pfeile nur in ihrer Richtung nutzen.

Merke

Ein Pfeil von A nach B heißt: Auf Seite A steht ein Verweis auf Seite B. Ein Weg zurück braucht einen eigenen Pfeil von B nach A, wie zwischen Selin und Jona.

Aufgabe

Was bedeutet jeder Pfeil?

Wähle zu jedem Eintrag das Passende.

Richtige Antwort: Pfeil von Mia zu Selin – Auf Mias Seite steht ein Link zu Selins Seite.; Pfeil von Selin zu Jona – Auf Selins Seite steht ein Link zu Jonas Seite.; Pfeil von Jona zu Tom – Auf Jonas Seite steht ein Link zu Toms Seite.

Der Pfeil beginnt an der Seite, auf der der Link steht, und zeigt auf die Seite, zu der er führt. Tom hat noch keinen Link.

Mehr dazu: Tim Berners-Lee: Information Management: A Proposal (1989, englisch)

Die Idee ist älter als du: 1989 schlug Tim Berners-Lee am Forschungszentrum CERN vor, Notizen und Texte als Netz zu verknüpfen. Er zeichnete Kringel und Pfeile und nannte die Kringel Knoten (nodes) und die Pfeile Links. Daraus entstand das World Wide Web.

Ein Linknetz am Rechner

Jetzt zeichnest du Links als Pfeile, nach einer Liste. Tippe zuerst die Seite an, auf der der Link steht, dann die Seite, zu der er führt. Der Pfeil zeigt vom ersten zum zweiten Namen.

Aufgabe

Aufgabe Nr. 1

Lege für jeden Link einen Pfeil an:

  • Die Seite von Jona hat einen Link zur Seite von Mia.
  • Die Seite von Jona hat einen Link zur Seite von Tom.
  • Die Seite von Jona hat einen Link zur Seite von Lea.
  • Die Seite von Selin hat einen Link zur Seite von Tom.
  • Die Seite von Selin hat einen Link zur Seite von Lea.
  • Die Seite von Mia hat einen Link zur Seite von Lea.

Deine Pfeile:

Noch keine Pfeile.

Aufgabe Nr. 1

Lege für jeden Link einen Pfeil an:

  • Die Seite von Jona hat einen Link zur Seite von Mia.
  • Die Seite von Jona hat einen Link zur Seite von Tom.
  • Die Seite von Jona hat einen Link zur Seite von Lea.
  • Die Seite von Selin hat einen Link zur Seite von Tom.
  • Die Seite von Selin hat einen Link zur Seite von Lea.
  • Die Seite von Mia hat einen Link zur Seite von Lea.
Lösung

Jona → Mia, Jona → Tom, Jona → Lea, Selin → Tom, Selin → Lea, Mia → Lea
