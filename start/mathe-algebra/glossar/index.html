Glossar

Die Begriffe dieser App, von A bis Z, jeder mit der Seite, die ihn erklärt.

Ausmultiplizieren

Ein Produkt mit Klammern in eine Summe ohne Klammern umformen: Jedes Glied der einen Klammer wird mit jedem Glied der anderen multipliziert.

Erklärt auf der Seite Zwei Klammern multiplizieren

Faktorisieren

Eine Summe als Produkt schreiben, zum Beispiel x2+6x+9=(x+3)2.

Erklärt auf der Seite Binome rückwärts

Glied

Ein Teil einer Summe, mit seinem Vorzeichen. Steht in einer Klammer ein Minus, gehört es zum Glied dahinter: (x−1) hat die Glieder x und −1.

Erklärt auf der Seite Zwei Klammern multiplizieren

Mittelglied

Das Glied in der Mitte einer binomischen Formel: 2ab bei (a+b)2, −2ab bei (a−b)2. Bei der dritten Formel gibt es kein Mittelglied.

Erklärt auf der Seite Erste binomische Formel
