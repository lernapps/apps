Päckchen links und rechts

Steht in einer Gleichung das x links und rechts, weißt du nicht, womit du anfangen sollst. Dann sammelst du zuerst die x auf einer Seite. Ein Päckchen ist das x: Es enthält überall gleich viele Gewichte. Du nimmst auf beiden Seiten gleich viele Päckchen weg.

Zwei Wege führen zur Lösung von 3⋅x+2=x+8. Weg 1: Probiere in der Tabelle. Er passt, wenn du die Lösung schätzen kannst. Beide Seiten hängen von x ab. Achte darauf, ob der Unterschied zwischen links und rechts kleiner wird.

3 · x + 2 = x + 8

Trag eine Zahl für x ein.

Tabelle zum Probieren für 3 · x + 2 = x + 8. Für x = 1 ist links 5 und rechts 9: links ist kleiner. Für x = 5 ist links 17 und rechts 13: links ist größer. Für x = 3 ist links 11 und rechts 11: beide Seiten sind gleich. Die Lösung ist 3.

Weg 2: Die Waage. Sie passt, wenn du ohne Raten ans Ziel willst. Sammle zuerst alle Päckchen auf einer Seite: Nimm auf beiden Seiten gleich viele weg. Danach steht x nur noch auf einer Seite, und du löst wie bei einer gewöhnlichen Gleichung.

3 · x + 2 = x + 8

Sammle zuerst die Päckchen auf einer Seite: Nimm auf beiden Seiten gleich viele weg.

Waage für 3 · x + 2 = x + 8. Auf beiden Seiten ein Päckchen wegnehmen: 2 · x + 2 = 8. Auf beiden Seiten 2 Gewichte wegnehmen: 2 · x = 6. Beide Seiten durch 2 teilen: x = 3.

Beide Wege geben x=3. Zur Probe setzt du 3 links und rechts ein: 3⋅3+2=11 und 3+8=11. Die Tabelle sagt dir nur, ob du triffst. Das Umformen führt dich ohne Raten ans Ziel.

Erst x sammeln

Damit du Gleichungen mit x auf beiden Seiten sicher löst, brauchst du eine feste Reihenfolge der Schritte.

Löse 5 · x − 4 = 2 · x + 11

Eine Zeile je Schritt. Rechts steht, was du auf beiden Seiten getan hast.
GleichungRand
5 · x − 4 = 2 · x + 11Start
3 · x − 4 = 11− 2 · x
3 · x = 15+ 4
x = 5: 3

Probe: Links ist 5⋅5−4=21, rechts 2⋅5+11=21. Das stimmt.

Merke

Erst die x auf eine Seite sammeln, dann die Zahlen auf die andere Seite bringen, dann durch die Zahl vor dem x teilen. Am besten sammelst du dort, wo mehr x liegen: Dann bleibt eine positive Zahl vor dem x.

Wenn das x verschwindet

Nicht jede Gleichung hat genau eine Lösung. Du willst wissen, woran du das erkennst. Manchmal bleiben beim Sammeln keine Päckchen übrig. Probiere 2⋅x+3=2⋅x+7 in der Tabelle: Was fällt dir auf?

2 · x + 3 = 2 · x + 7

Trag eine Zahl für x ein.

Tabelle zum Probieren für 2 · x + 3 = 2 · x + 7. Für jede Zahl ist links 4 weniger als rechts: Für x = 1 steht 5 < 9, für x = 4 steht 11 < 15. Beide Seiten sind nie gleich.

Was nach dem Sammeln der x übrig bleibt, sagt dir die Lösung.
GleichungNach dem SammelnLösung
2 · x + 3 = 2 · x + 73 = 7 (falsch)keine Lösung
2 · x + 6 = 2 · x + 66 = 6 (wahr)alle Zahlen
3 · x + 2 = x + 82 · x = 6x = 3

Ist die Aussage am Ende falsch, gibt es keine Lösung: Egal welche Zahl du einsetzt, links und rechts bleiben verschieden. Ist sie immer wahr, ist jede Zahl eine Lösung. Hier hilft dir die Tabelle: Du siehst, dass der Unterschied immer gleich bleibt.

Übung

Hier übst du das Sammeln der x und erkennst, wie viele Lösungen eine Gleichung hat.

5 · x + 4 = 2 · x + 19

Trag eine Zahl für x ein.

Tabelle zum Probieren für 5 · x + 4 = 2 · x + 19. Probier Zahlen für x aus, bis beide Seiten gleich sind.

5 · x + 4 = 2 · x + 19

Sammle zuerst die Päckchen auf einer Seite: Nimm auf beiden Seiten gleich viele weg.

Waage für 5 · x + 4 = 2 · x + 19. Auf beiden Seiten 2 Päckchen wegnehmen: 3 · x + 4 = 19. Auf beiden Seiten 4 Gewichte wegnehmen: 3 · x = 15. Beide Seiten durch 3 teilen: x = 5.

Aufgabe

Löse 5 · x + 4 = 2 · x + 19 mit der Tabelle und mit der Waage. Welche Zahl ist x?

Richtige Antwort: 5

3 · x = 15, also x = 5. Probe: 5 · 5 + 4 = 29 und 2 · 5 + 19 = 29. Die Tabelle braucht mehr Versuche.
