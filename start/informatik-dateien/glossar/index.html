Glossar

Die Begriffe dieser App, von A bis Z, jeder mit der Seite, die ihn erklärt.

Cloud-Speicher

Ein Cloud-Speicher liegt auf Rechnern einer Firma. Du kommst über das Internet an deine Dateien, meist mit Name und Passwort.

Erklärt auf der Seite Speicherorte vergleichen

Datei

Eine Datei ist ein gespeichertes Stück Daten mit einem Namen, zum Beispiel ein Foto, ein Lied oder ein Text. In einer Datei liegt nichts weiter, darum ist sie im Baum immer ein Blatt.

Erklärt auf der Seite Ordner und Dateien

Dateiendung

Die Endung ist der letzte Teil des Dateinamens, nach dem Punkt. Sie zeigt die Art der Datei, zum Beispiel .jpg für ein Foto, .mp3 für etwas zum Hören, .txt für einen Text.

Erklärt auf der Seite Ordner und Dateien

Ordner

Ein Ordner ist ein Platz mit Namen. Darin liegen Dateien und weitere Ordner, die zusammengehören.

Erklärt auf der Seite Ordner und Dateien

Passwort-Manager

Ein Programm, das deine Passwörter verschlüsselt aufbewahrt, also in einer Geheimschrift, die man nur mit deinem Hauptpasswort lesen kann. Du merkst dir nur noch ein langes Hauptpasswort.

Erklärt auf der Seite Sichere Passwörter

Pfad

Jede Datei und jeder Ordner hat einen Pfad. Das ist der Weg im Ordnerbaum, von der Wurzel bis dorthin. Zwischen die Namen setzt man einen Schrägstrich /.

Erklärt auf der Seite Dateipfad

Schadsoftware

Software, die auf einem Gerät Schaden anrichten soll, zum Beispiel Daten stehlen, löschen oder sperren. Sie ist ein Programm wie jedes andere, nur mit bösem Zweck.

Erklärt auf der Seite Schadsoftware

Sicherheitslücke

Ein Fehler in einem Programm, durch den Schadsoftware oder Angreifer hineinkommen können. Ein Update schließt sie.

Erklärt auf der Seite Schutzsoftware und Updates

Sicherungskopie

Eine Kopie deiner Dateien an einem anderen Ort, zum Beispiel auf einem Stick oder in der Cloud. Das Original bleibt, wo es ist.

Erklärt auf der Seite Datensicherung

Speicherort

Ein Speicherort ist der Platz, an dem eine Datei liegt, zum Beispiel ein Tablet, ein USB-Stick oder eine Cloud.

Erklärt auf der Seite Speicherorte vergleichen

Zeichenvorrat

Alle Zeichen, aus denen ein Passwort bestehen darf, zum Beispiel 26 kleine Buchstaben oder 10 Ziffern.

Erklärt auf der Seite Sichere Passwörter

Zwei-Faktor-Anmeldung

Du meldest dich mit zwei Dingen aus verschiedenen Arten an, zum Beispiel etwas, das du weißt (Passwort), und etwas, das du hast (Handy mit Code). Ist das Passwort verraten, bleibt das Konto meist trotzdem geschützt, solange niemand auch den Code hat.

Erklärt auf der Seite Sichere Passwörter
