Glossary

The terms of this app, from A to Z, each with the page that explains it.

cloud storage

Cloud storage is on the computers of a company. You reach your files over the internet, usually with a name and a password.

Explained on the page Comparing storage locations

file

A file is a stored piece of data with a name, for example a photo, a song or a text. Nothing else is inside a file, so in the tree it is always a leaf.

Explained on the page Files and folders

file extension

The extension is the last part of the file name, after the dot. It shows the kind of file, for example .jpg for a photo, .mp3 for something to listen to, .txt for a text.

Explained on the page Files and folders

folder

A folder is a place with a name. It holds files and more folders that belong together.

Explained on the page Files and folders

path

Every file and every folder has a path. It is the way in the folder tree, from the root to there. You put a slash / between the names.

Explained on the page File paths

storage location

A storage location is the place where a file is kept, for example a tablet, a USB stick or a cloud.

Explained on the page Comparing storage locations
