Where is Mia's speech?

Yesterday Mia wrote her speech for German class and saved it. Today she cannot find it.

On this page you will learn how to store files so that you can find them again. For this you need the tree that you already know.

Exercise

What helps Mia most to find her speech now and later?

  • She puts everything that belongs together in one fixed place, for example everything for school. right answer

    Then she knows where to look, even a year from now.

  • She looks in the list “Recent”.

    That only helps today. “Recent” shows the last files, but it is not a place. Soon the speech may be gone from the list.

  • She saves the speech again, then it is sure to be there.

    It is already saved. The question is where. Without a fixed place, Mia will not know next time either.

If something has a fixed place, you can find it again.

Mia's folder tree

Mia makes a folder for everything that belongs together: one for school, one for photos, one for music. After that, her tablet looks like a tree: at the top is the root (light blue), which is the tablet itself. Below it are the folders (with a yellow folder sign). At the very bottom are the files with a dashed border, which are the leaves. Inside the folder Photos there is another folder: Seeberg, for the photos of the class trip.

Mia's folder tree. At the top is the root “Mia's tablet”. Below it are three folders: School, Photos and Music. In the folder School there is speech.txt. In the folder Photos there are the folder Seeberg and party.jpg; in the folder Seeberg there is lake.jpg. In the folder Music there is song.mp3. The files have a dashed border; their name is in two lines, the name at the top, the extension below.

folder

A folder is a place with a name. It holds files and more folders that belong together.

file

A file is a stored piece of data with a name, for example a photo, a song or a text. Nothing else is inside a file, so in the tree it is always a leaf.

file extension

The extension is the last part of the file name, after the dot. It shows the kind of file, for example .jpg for a photo, .mp3 for something to listen to, .txt for a text.

Tidying up in the file manager

A file manager is a program you use to open folders and move files. On a tablet it usually shows only one folder at a time:

  • Tap a folder and it opens. At the top it says where you are.
  • “Up” takes you back one folder.
  • “Cut” remembers a file. It stays where it is until you paste. Then open the folder where it should go and tap “Paste”. Cut and paste together mean: move.

New files often end up in the folder “Downloads”. Put the new file into a folder that fits and then press “Check”.
