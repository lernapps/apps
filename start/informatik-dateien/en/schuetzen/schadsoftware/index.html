What malware is

malware

Software that is meant to do harm on a device, for example steal, delete or lock data. It is a program like any other, only with a bad purpose.

Four kinds of malware (as the BSI describes them)
KindWhat it does
viruscopies itself into other programs or files and spreads when they are run or shared
wormspreads on its own, without another program
Trojanpretends to be a useful program; does not copy itself
ransomwarelocks your data and asks for money, the ransom

This is how it often gets in: as an email attachment, with a free download, on an unknown USB stick or as a macro in a document. A macro is a small program inside a document.

How you can often spot it: the device suddenly gets slow, windows open by themselves, files no longer open, or a message asks for money. More from the BSI (in German)

What do you do then?

Jona and the school laptop

  1. Jona tells a teacher straight away. He is not ashamed: reporting it helps everyone.
  2. The teacher takes the laptop off the network, by turning off the Wi-Fi or pulling out the cable, so that nothing spreads.
  3. Jona does not plug the stick in anywhere again and hands it in.
  4. Adults take care of the laptop. If there is a backup, the data is not lost.

Exercise

Three worked tasks, each with its solution:

  1. Task no. 1

    Selin gets an email from an unknown address: “Your bill, please open”, with a file attached. She has not opened the file yet. In which way could malware get onto the device here?

    • email attachment
    • free download
    • unknown USB stick
    • macro in a document
    Hint

    Where does the new thing that is meant to go onto the device come from in this case?

    Solution
    1. The file is attached to an email from an unknown address. So: email attachment.

    Right answer: email attachment

  2. Task no. 2

    Mia opens a document, and a message asks: “Please enable macros to see the content.” In which way could malware get onto the device here?

    • email attachment
    • free download
    • unknown USB stick
    • macro in a document
    Hint

    Where does the new thing that is meant to go onto the device come from in this case?

    Solution
    1. The document wants to run a macro, a small program inside it. So: macro in a document.

    Right answer: macro in a document

  3. Task no. 3

    Jona finds a USB stick in the school yard and plugs it into the school laptop to see whose it is. In which way could malware get onto the device here?

    • email attachment
    • free download
    • unknown USB stick
    • macro in a document
    Hint

    Where does the new thing that is meant to go onto the device come from in this case?

    Solution
    1. Nobody knows what is on a stick that was found. So: unknown USB stick.

    Right answer: unknown USB stick
