Wann kosten beide gleich viel?

Auf der Seite davor hast du aus dem Graphen für Tarif A (y = x + 6) und Tarif B (y = 2 · x + 2) den Schnittpunkt abgelesen. Das war nur so genau, wie du den Graphen lesen kannst. Jetzt berechnest du ihn. Beide Gleichungen sind schon nach y aufgelöst. Dann müssen die rechten Seiten gleich sein, wenn die Kosten gleich sind. Für A und B: x + 6 = 2 · x + 2.

Gleichsetzen in drei Schritten

Wenn du den Tarif-Wechsel genau berechnen willst, statt ihn abzulesen, und in beiden Gleichungen schon y allein steht, setzt du die Terme gleich.

Gleichsetzungsverfahren

Beim Gleichsetzungsverfahren setzt du die beiden Terme für y gleich, löst nach x auf und rechnest y aus. Beispiel: x + 6 = 2 · x + 2 gibt x = 4, dann y = 4 + 6 = 10.

Schritt 1: Beide Terme für y gleichsetzen. Schritt 2: Die entstandene Gleichung nach x lösen. Schritt 3: x in eine Gleichung einsetzen und y berechnen. Dann die Probe in beiden Gleichungen.

Merke

Schreibe jede Umformung in eine neue Zeile und mache die Probe in beiden Gleichungen, nicht nur in einer.

Übung

Gib jedem Eintrag seinen Platz: 1 für den ersten.

Richtige Antwort: 1. Beide Terme für y gleichsetzen., 2. Die Gleichung nach x auflösen., 3. x in eine Gleichung einsetzen und y berechnen., 4. Die Probe in beiden Gleichungen machen.

Erst gleichsetzen, dann x bestimmen, dann y berechnen, am Ende prüfen.

Aufgabe

Drei Beispielaufgaben, jede mit ihrer Lösung:

  1. Aufgabe Nr. 1

    Löse das System mit dem Gleichsetzungsverfahren: y = 4 · x + 2 und y = 2 · x + 6. Wie groß ist x?

    Tipp

    Setze 4 · x + 2 = 2 · x + 6. Bringe alle x auf eine Seite, alle Zahlen auf die andere.

    Lösung
    1. 4 · x + 2 = 2 · x + 6
    2. (2) · x = 4
    3. x = 4 : 2 = 2.

    Richtige Antwort: 2

  2. Aufgabe Nr. 2

    Löse das System mit dem Gleichsetzungsverfahren: y = 4 · x + 1 und y = 1 · x + 10. Wie groß ist x?

    Tipp

    Setze 4 · x + 1 = 1 · x + 10. Bringe alle x auf eine Seite, alle Zahlen auf die andere.

    Lösung
    1. 4 · x + 1 = 1 · x + 10
    2. (3) · x = 9
    3. x = 9 : 3 = 3.

    Richtige Antwort: 3

  3. Aufgabe Nr. 3

    Löse das System mit dem Gleichsetzungsverfahren: y = 2 · x + 1 und y = 1 · x + 4. Wie groß ist x?

    Tipp

    Setze 2 · x + 1 = 1 · x + 4. Bringe alle x auf eine Seite, alle Zahlen auf die andere.

    Lösung
    1. 2 · x + 1 = 1 · x + 4
    2. (1) · x = 3
    3. x = 3 : 1 = 3.

    Richtige Antwort: 3

Aufgabe

Tarif A: y = 2 · x + 4. Tarif B: y = 4 · x + 2. Bei welchem x kosten beide gleich viel?

Richtige Antwort: 1

2⋅x+4=4⋅x+2, also 2=2⋅x und x=1. Dann y=6.

Aufgabe

Das System lautet y = 3 · x + 1 und y = x + 7. Was ist der erste Schritt beim Gleichsetzen?

  • 3 · x + 1 = x + 7 aufschreiben richtige Antwort

    Beide Terme sind für das gleiche y gleich groß. Daraus entsteht eine Gleichung nur mit x.

  • 3 · x + 1 + x + 7 rechnen

    Addieren gehört zu einem anderen Verfahren. Hier setzt du die Terme gleich.

  • y = 0 setzen

    y = 0 liefert die Nullstelle, nicht die Lösung des Systems.

Beim Gleichsetzen schreibst du beide Terme als Gleichung auf.
