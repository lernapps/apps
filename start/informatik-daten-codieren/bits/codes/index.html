Nachrichten ohne Worte

Die 6b ist mit dem Zug am Seeberg angekommen und läuft vom Bahnhof zur Jugendherberge. Selin zeigt auf die Straße: Überall sind Nachrichten ohne Worte, an der Ampel, auf der Milchtüte in Mias Tasche, auf den Schildern.

Im ersten Kapitel hast du gesehen, wie aus Information Daten werden. Auf dieser Seite lernst du Codes kennen: feste Regeln, mit denen man Daten in andere Zeichen übersetzt.

Aufgabe

Was bedeutet das Zeichen? Ordne zu.

Wähle zu jedem Eintrag das Passende.

Richtige Antwort: Das rote Ampelmännchen leuchtet. – Stehen bleiben.; Das grüne Ampelmännchen leuchtet. – Du darfst gehen.; Die Kasse piept beim Strichcode der Milch. – Die Kasse hat die Nummer der Ware gelesen.

Jedes Zeichen steht nach einer festen Regel für eine Bedeutung. Wer die Regel kennt, versteht das Zeichen ohne Worte.

Der Morsecode

Am Seeberg schlafen Jona und Selin in verschiedenen Zimmern. Am Abend wollen sie sich mit der Taschenlampe Nachrichten schicken. Unterwegs üben sie schon. Dafür nehmen sie den Morsecode: Jeder Buchstabe ist eine Folge aus kurzen Blinkzeichen (·) und langen (–). Zwischen zwei Buchstaben machen sie eine Pause, hier eine Lücke.

Code

Ein Code ist eine feste Regel, die Zeichen in andere Zeichen übersetzt. Codieren heißt, eine Nachricht mit dem Code übersetzen. Decodieren heißt, sie zurückübersetzen.

Merke

Sender und Empfänger müssen dieselbe Codetabelle kennen. Und die Pausen gehören zum Code. Ohne Pause wird aus „· · ·“ (S) vielleicht „· ·“ und „·“ (I und E).

Übung

Aufgabe

Selin blinkt: · · · | · | · . Die Striche | sind Pausen. Welches Wort ist das?

  • SEE richtige Antwort

    · · · ist S, dann zweimal · für E: SEE, wie im Seeberg.

  • EEEEE

    So liest du es, wenn du die Pausen nicht beachtest. Die ersten drei Punkte gehören zu einem Buchstaben.

  • OEE

    O ist dreimal lang, – – –. Selin blinkt aber dreimal kurz.

Mit den Pausen ist jeder Buchstabe klar. Ohne Pausen könnte man die Zeichen ganz anders lesen.
