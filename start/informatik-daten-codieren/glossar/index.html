Glossar

Die Begriffe dieser App, von A bis Z, jeder mit der Seite, die ihn erklärt.

analog

Analog heißt, ein Wert ändert sich stufenlos und kann jeden Zwischenwert haben, wie eine Schallwelle oder die Zeiger einer Uhr.

Erklärt auf der Seite Analog und digital

Baum

Ein Baum zeigt Daten, die ineinander stecken. Er besteht aus Knoten und Kanten. Ganz oben steht ein Knoten, die Wurzel. Knoten ohne Knoten darunter heißen Blätter.

Erklärt auf der Seite Der Baum

Binärzahl

Eine Binärzahl schreibt man nur mit den Ziffern 0 und 1. Jede 1 zählt so viel wie der Wert ihrer Karte.

Erklärt auf der Seite Die Bit-Karten

Bit

Ein Bit ist ein Zeichen mit nur zwei möglichen Werten, 0 oder 1.

Erklärt auf der Seite Die Bit-Karten

Byte

Ein Byte sind 8 Bit, wie eine Reihe aus acht Bit-Karten. In einem Byte kann man zum Beispiel eine Zahl von 0 bis 255 speichern.

Erklärt auf der Seite Bit und Byte

Code

Ein Code ist eine feste Regel, die Zeichen in andere Zeichen übersetzt. Codieren heißt, eine Nachricht mit dem Code übersetzen. Decodieren heißt, sie zurückübersetzen.

Erklärt auf der Seite Codes im Alltag

Codetabelle

Eine Codetabelle legt fest, welche Zahl zu welchem Zeichen gehört. Die Zahl speichert der Computer als Binärzahl.

Erklärt auf der Seite Zeichen werden Zahlen

Daten

Daten sind Zeichen, die nach festen Regeln aufgeschrieben sind, zum Beispiel Zahlen, Wörter oder ein Datum. So kann man sie speichern und weitergeben.

Erklärt auf der Seite Information und Daten

digital

Digital heißt, ein Wert wird nur zu einzelnen Zeitpunkten und in Stufen als Zahl festgehalten, im Computer als Binärzahl.

Erklärt auf der Seite Analog und digital

Information

Eine Information ist die Bedeutung, die jemand aus Daten versteht, weil er den Zusammenhang kennt.

Erklärt auf der Seite Information und Daten

Pixel

Ein Pixel ist der kleinste Punkt eines Bildes. Jedes Pixel hat genau eine Farbe.

Erklärt auf der Seite Bilder aus Pixeln

Pixelgrafik

Eine Pixelgrafik speichert ein Bild als Raster aus Zeilen und Spalten. Für jedes Pixel speichert sie seine Farbe als Zahl.

Erklärt auf der Seite Bilder aus Pixeln

Schlüssel

Der Schlüssel ist das Geheimnis, das man zum Ver- und Entschlüsseln braucht, zum Beispiel eine Zahl. Das Verfahren dürfen alle kennen, den Schlüssel nicht.

Erklärt auf der Seite Die Geheimschrift

Vektorgrafik

Eine Vektorgrafik speichert ein Bild als Formen wie Kreis, Linie und Rechteck, jede mit ihren Zahlen, zum Beispiel Mittelpunkt, Radius und Farbe.

Erklärt auf der Seite Pixel oder Vektor?

Verschlüsselung

Beim Verschlüsseln macht man aus dem lesbaren Klartext mit einem Verfahren und einem geheimen Schlüssel einen Geheimtext. Nur wer den Schlüssel kennt, soll ihn wieder lesen können.

Erklärt auf der Seite Die Geheimschrift
