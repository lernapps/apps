How did class 6b choose?

How did class 6b pick Seeberg? They had a vote first. All 26 children had one vote each. Selin made a tally mark on the board for every vote, in groups of five.

On the page before you worked out what data in a table means. On this page you show the same data in different ways and choose the form that answers a question fastest.

The same data, three forms

Jona writes the votes in a table. Mia draws a bar chart. Selin writes a sentence for the parents. All three show the same data.

Jona's table
PlaceVotes
Seeberg11
Falkenburg7
Bärenhöhle5
Lindenzoo3

Selin's sentence: “Seeberg got the most votes, 11 out of 26. So that is where we are going.”

Remember

No form is always the best. A table shows exact numbers. A bar chart shows at a glance what is bigger. A text explains what the data means. Choose the form that answers your question fastest.
