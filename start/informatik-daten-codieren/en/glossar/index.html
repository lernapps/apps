Glossary

The terms of this app, from A to Z, each with the page that explains it.

analog

Analog means a value changes smoothly and can have any value in between, like a sound wave or the hands of a clock.

Explained on the page Analog and digital

binary number

A binary number is written only with the digits 0 and 1. Each 1 counts as much as the value of its card.

Explained on the page The bit cards

bit

A bit is a symbol with only two possible values, 0 or 1.

Explained on the page The bit cards

bitmap image

A bitmap image stores a picture as a grid of rows and columns. For each pixel it stores its colour as a number.

Explained on the page Pictures made of pixels

byte

One byte is 8 bits, like a row of eight bit cards. In one byte you can store, for example, a number from 0 to 255.

Explained on the page Bits and bytes

character set

A character set (code table) fixes which number belongs to which character. The computer stores the number as a binary number.

Explained on the page Characters become numbers

code

A code is a fixed rule that turns symbols into other symbols. To encode means to turn a message into the code. To decode means to turn it back.

Explained on the page Codes in everyday life

data

Data is symbols written down by fixed rules, for example numbers, words or a date. That way you can store it and pass it on.

Explained on the page Information and data

digital

Digital means a value is only recorded at single moments in time and in steps as a number, in a computer as a binary number.

Explained on the page Analog and digital

encryption

When you encrypt, you turn the readable plaintext into a ciphertext with a method and a secret key. Only someone who knows the key is meant to be able to read it again.

Explained on the page Secret writing

information

Information is the meaning that someone gets from data because they know the context.

Explained on the page Information and data

key

The key is the secret you need to encrypt and decrypt, for example a number. Everyone may know the method, but not the key.

Explained on the page Secret writing

pixel

A pixel is the smallest dot of a picture. Each pixel has exactly one colour.

Explained on the page Pictures made of pixels

tree

A tree shows data that fits inside other data. It is made of nodes and edges. At the very top there is one node, the root. Nodes with no nodes below them are called leaves.

Explained on the page The tree

vector image

A vector image stores a picture as shapes such as circles, lines and rectangles, each with its numbers, for example the centre, the radius and the colour.

Explained on the page Pixels or vectors?
