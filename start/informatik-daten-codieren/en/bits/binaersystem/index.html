A room without a number

Class 6b has arrived at the youth hostel “Am Seeberg”. Jona is looking for his room. But there is no room number on the doors. On every door there are five cards. A card that is face up shows dots. A card that is face down shows its back, and the back has no dots. Above each card it says how many dots it has when it is face up. This number is the value of the card.

Here you will learn to write any number with only 0 and 1: a code with only two symbols.

Exercise

How many dots do the face-up cards show altogether? That is the room number.

Right answer: 13

8 + 4 + 1 = 13. Jona sleeps in room 13.

Solution

Right answer: 13

8 + 4 + 1 = 13. Jona sleeps in room 13.

One card is one bit

Each card is either face up or face down. For face up you write 1, for face down 0. Then Jona's door shows: face down, face up, face up, face down, face up. In short: 01101. These digits in a row are called a bit string.

bit

A bit is a symbol with only two possible values, 0 or 1.

binary number

A binary number is written only with the digits 0 and 1. Each 1 counts as much as the value of its card.

Remember

Each card is worth twice as much as the card to its right. The biggest card is on the left. That is why it matters where a 1 is, not just how many ones there are.

The value of a place is called its place value. You know this from ones, tens and hundreds: there, each place is worth ten times as much (decimal system). With the cards, each place is worth twice as much (binary system). Zeros at the very front change nothing: 00101 is the same number as 101.

Bit string: 00000 · Number: 0

Five bit cards with the values 16, 8, 4, 2 and 1, all face down. When you tap a card, it turns over. Below the cards you can read which number the face-up cards show, for example “Bit string: 00101 · Number: 5” for the cards 4 and 1. With all the cards face down it is 00000, which is 0. With all face up it is 11111, which is 31.

Example

Which room is 10110?

  1. Look at the value above each digit: 16, 8, 4, 2, 1.
  2. Take only the values that have a 1 below them: 16, 4 and 2.
  3. Add them up: 16 + 4 + 2 = 22.

The binary number 10110 is the decimal number 22. Mia sleeps in room 22 with Selin.

The binary numbers 00111 and 11100 are the same number, because both have three ones.

Right answer: The statement is false.

It matters where the ones are. 00111 is 4 + 2 + 1 = 7, but 11100 is 16 + 8 + 4 = 28.

Exercise

Three worked tasks, each with its solution:

  1. Task no. 1

    Which decimal number is the binary number 01111?

    Hint

    Draw five cards and write 16, 8, 4, 2, 1 above them.

    Solution
    1. Values above the digits: 16 · 0, 8 · 1, 4 · 1, 2 · 1, 1 · 1.
    2. Only the cards with a 1 count. Together that makes 15.

    Right answer: 15

  2. Task no. 2

    Which decimal number is the binary number 10010?

    Hint

    Draw five cards and write 16, 8, 4, 2, 1 above them.

    Solution
    1. Values above the digits: 16 · 1, 8 · 0, 4 · 0, 2 · 1, 1 · 0.
    2. Only the cards with a 1 count. Together that makes 18.

    Right answer: 18

  3. Task no. 3

    Which decimal number is the binary number 01011?

    Hint

    Draw five cards and write 16, 8, 4, 2, 1 above them.

    Solution
    1. Values above the digits: 16 · 0, 8 · 1, 4 · 0, 2 · 1, 1 · 1.
    2. Only the cards with a 1 count. Together that makes 11.

    Right answer: 11
