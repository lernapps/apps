A character set

So that all devices use the same numbers, there is a fixed character set, a code table. The best known one is called ASCII. It has 128 characters with the codes 0 to 127: capital letters, small letters, digits, punctuation marks and invisible control characters such as “new line”, but no letters like Ä, Ö, Ü. A has the number 65, B 66, C 67 and so on up to Z with 90. The space has 32, small a 97. For Selin's message, A to Z and the space are enough.

character set

A character set (code table) fixes which number belongs to which character. The computer stores the number as a binary number.

Remember

With ASCII, each character fits into one byte, that is, on eight bit cards. The codes only go up to 127, so card 128 always stays face down. A word with 5 letters needs 5 bytes, which is 40 bits.

Example

The word HI as bytes

  1. Code of H: A = 65, B = 66 … H is the 8th letter, so 65 + 7 = 72.
  2. 72 = 64 + 8, as a byte 01001000.
  3. Code of I: 65 + 8 = 73 = 64 + 8 + 1, as a byte 01001001.

HI is stored as 01001000 01001001, two bytes or 16 bits.

Solution

Right answer: The statement is false.

ASCII only knows letters without accents. For Ä, € and emojis there is Unicode, with more than 170,000 characters.

And Ä, € or 😀?

For almost all the writing systems in the world there is the character set Unicode. Today it has more than 170,000 characters. The first 128 are exactly the ASCII characters. But one byte only gives 256 different numbers. So for the other characters, the phone needs more bits. Following a rule called UTF-8, it stores a character in 1 to 4 bytes: A in 1 byte, Ä in 2, € in 3 and 😀 in 4 bytes.
