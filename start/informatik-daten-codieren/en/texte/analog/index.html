A voice message

In class 7b's chat, Mia sends a voice message: “I'll bring the ball!”

Jona: Text is bytes, I know that now. But how does Mia's voice get into 0 and 1?

A voice is a sound wave. It changes smoothly, without jumps. On this page you will see how it turns into numbers that the phone stores as bits.

Measuring and rounding

analog

Analog means a value changes smoothly and can have any value in between, like a sound wave or the hands of a clock.

digital

Digital means a value is only recorded at single moments in time and in steps as a number, in a computer as a binary number.

The microphone in the phone turns the sound into an electrical voltage. It changes smoothly with the voice, so it is still analog. When digitising, the phone then takes two steps:

  1. Sampling: it measures the voltage at equal intervals, for example 8000 times every second. Each measurement is called a sample.
  2. Quantising (rounding): it rounds each measured value to the nearest allowed level and stores that level's number as a binary number. With 2 bits there are 4 levels (00, 01, 10, 11), with 3 bits already 8. The number of bits per sample is called the bit depth.

Remember

Something gets lost between two measuring points and between two levels. More points and more bits make the digital voice more exact, but also bigger.

Move them, also with the arrow keys, and watch how close the staircase gets to the wave.

A sound wave with the stored values above it as a staircase. Two sliders set how often it is measured (2 to 32 measuring points) and how many bits each measured value has (1 to 4).

  • 4 points, 1 bit: 2 levels, 4 bits altogether. The staircase has little to do with the wave.
  • 8 points, 2 bits: 4 levels, 16 bits altogether. The shape of the wave can roughly be seen.
  • 32 points, 4 bits: 16 levels, 128 bits altogether. The staircase lies close to the wave.

Exercise

Three worked tasks, each with its solution:

  1. Task no. 1

    Each measured value is stored with 3 bits. How many different levels are there?

    Hint

    1 bit: 2 levels, 2 bits: 4 levels, 3 bits: …

    Solution
    1. Each bit doubles the number of levels. With 3 bits there are 8 levels.

    Right answer: 8

Exercise

Three worked tasks, each with its solution:

  1. Task no. 1

    A device measures 8,000 times per second and stores each measured value with 16 bits. How many bits is that in one second?

    Solution
    1. 8,000 measured values × 16 bits = 128,000 bits per second.

    Right answer: 128,000 bits

  2. Task no. 2
