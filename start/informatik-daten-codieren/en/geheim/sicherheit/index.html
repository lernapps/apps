Solution

Trying every key

With Caesar there are only 25 keys, from 1 to 25. The key 26 would be like 0: nothing changes. Anyone who tries all 25 will definitely find the message, even without the key. With the scytale and 9 letters there are even fewer sensible keys.

A mixed alphabet is different: each letter gets any other letter, for example A becomes Q, B becomes M and so on. Then the key is the whole list. There are so many of these that the number has 27 digits. That is much more secure than Caesar, but still not secure: because each letter is always replaced by the same one, common letters such as E give away something about the text.

Remember

A secure method needs so many keys that nobody can try them all, and the key has to stay secret. That is needed, but not enough: the method must not have any other weak spot either. Everyone may know the method itself. Today computers encrypt with methods that experts have checked for a long time, and with huge keys. You protect yourself by making your password long and never telling it to anyone.
