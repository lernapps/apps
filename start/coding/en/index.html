Coding workshop

You program with blocks. Kiko, a robot, runs your program, one command after another: it walks through mazes and draws pictures. For year 7 and 8 (age 12 to 14).

How it works

  • Choose a task.
  • Drag blocks onto the work area and snap them together. With the keyboard: Tab to the blocks, Enter adds a block.
  • Press “Run”. With “One step” you see each command on its own.
  • Some tasks try your program in several mazes. It has to work in all of them.
  • In the prediction tasks the program is ready: you predict what Kiko does, then you compare with “Run”.

What you learn

  • I can put commands in the right order (a sequence).
  • I can make commands run several times with “repeat … times” (a loop that counts).
  • I can make commands repeat with “while … do” until a condition is no longer true (a loop with a condition).
  • I can use “if … then … else” to choose what happens depending on a condition (a choice).
  • I can carry out an algorithm step by step by hand and so find its result.

For teachers and apps

Other apps send the workshop a task as a link. This is how:

  • Write the task as JSON following the schema. Worlds: maze and drawing (turtle).
  • On the page “Build your own task” (in the list above) you check it, try it out and copy the link.
  • A German explainer links the German page of the workshop (/coding/app/), an English one the English page (/coding/en/app/).
  • At build time the check script checks the task and a model solution, for example with “node challenge-check.v1.mjs task.json solution.json”.
  • The “Back” button leads to the address in “back.url” and adds “#werkstatt=task-id:geloest” or “:offen”.

To print

To start without a computer: Kiko command cards and a board, A4, readable in black and white too. The cards have the same words and colours as the blocks. One child is Kiko and follows the cards, the others lay out the program.
