Jona's smartphone and the training bag

Jona is 11 and in class 6b, like Selin and Mia. Jona's smartphone is a computer system: a computer inside it works by following programs. Some programs on it use AI, such as the photo app that recognises animals.

An AI like this has learned from many examples. Imagine a cloth bag full of animal cards, the training bag. Each card says whether it shows a dog or a cat. The machine finds patterns in these examples. So: What goes into the bag decides what comes out.

Exercise

The training bag only holds cards with cats. What happens when the machine sees a dog?

  • It probably calls it a cat. right answer

    It only knows cats as examples. It cannot say anything else.

  • It recognises it as a dog.

    For that it would need dogs as examples in the bag. But there are only cats in it.

  • It asks a person what it is.

    The machine does not ask by itself. It answers with what it learned from the examples.

What goes into the bag decides what comes out. With only cats as examples, the machine always says “cat”.
