Lang oder kurz?

Auf dieser Seite lernst du, Notenwerte von der ganzen bis zur Sechzehntelnote zu erkennen und ihre Dauer zu vergleichen. Du weißt schon, dass Töne lang oder kurz sein können. Note A heißt halbe Note, Note B Achtelnote. Die Namen verraten schon etwas:

Zwei Noten: A hat einen hohlen Kopf mit Hals, B einen gefüllten Kopf mit Hals und einem Fähnchen.

Aufgabe

Welche der beiden Noten dauert länger, die halbe Note A oder die Achtelnote B?

  • Note A richtige Antwort

    Note A ist eine halbe Note: hohler Kopf mit Hals. Sie dauert so lange wie vier Achtelnoten.

  • Note B

    Note B ist eine Achtelnote: Das Fähnchen macht eine Note kürzer, nicht länger.

  • Beide gleich lang

    Die beiden Zeichen sehen verschieden aus. Jedes Zeichen steht für eine andere Dauer.

Die Namen sind Brüche einer ganzen Note. Ein Halb ist mehr als ein Achtel, also dauert die halbe Note länger.

Immer halbieren

Ein Notenwert sagt, wie lange ein Ton dauert. Eine Note hat einen Kopf (das Oval), oft einen Hals (den senkrechten Strich) und manchmal Fähnchen (die Haken oben am Hals). Halbierst du eine ganze Note, bekommst du zwei halbe, aus einer halben zwei Viertel, und so weiter bis zur Sechzehntel.

Merke

Hohler Kopf ohne Hals: ganze Note. Hohler Kopf mit Hals: halbe. Gefüllter Kopf mit Hals: Viertel. Jedes Fähnchen halbiert noch einmal: ein Fähnchen Achtel, zwei Fähnchen Sechzehntel.

Im Bild ist die Linie die Zeit: Je weiter rechts eine Note steht, desto später kommt sie. Jede Zeile dauert gleich lang, so lange wie eine ganze Note.

Eine ganze Note: hohler Kopf ohne Hals, am Anfang der Zeile.

Zwei halbe Noten: hohler Kopf mit Hals, gleichmäßig über die Zeile verteilt.

Vier Viertelnoten: gefüllter Kopf mit Hals.

Acht Achtelnoten: gefüllter Kopf, Hals und ein Fähnchen.

Sechzehn Sechzehntelnoten: gefüllter Kopf, Hals und zwei Fähnchen.

Notenwert

Die Dauer einer Note, abzulesen an ihrem Zeichen; jeder Wert dauert halb so lange wie der nächstgrößere.

Beispiel: Viertel in Sechzehnteln

Wie viele Sechzehntelnoten dauern so lange wie eine Viertelnote?

  1. Eine Viertelnote halbiert: zwei Achtelnoten.
  2. Jede Achtelnote halbiert: je zwei Sechzehntelnoten.
  3. Zwei mal zwei: Eine Viertelnote dauert so lange wie 4 Sechzehntelnoten.

Drei Beispielaufgaben, jede mit ihrer Lösung:

  1. Aufgabe Nr. 1

    Wie viele Sechzehntelnoten dauern so lange wie eine halbe Note?

    Tipp

    Halbiere Schritt für Schritt: ganze, halbe, Viertel, Achtel, Sechzehntel. Jeder Schritt verdoppelt die Anzahl.

    Lösung
    1. Eine halbe Note dauert so lange wie 8 Sechzehntelnoten, jede der Sechzehntelnoten so lange wie 1 Sechzehntel. 8 : 1 = 8.

    Richtige Antwort: 8

  2. Aufgabe Nr. 2

    Wie viele Sechzehntelnoten dauern so lange wie eine ganze Note?

    Tipp

    Halbiere Schritt für Schritt: ganze, halbe, Viertel, Achtel, Sechzehntel. Jeder Schritt verdoppelt die Anzahl.

    Lösung
    1. Eine ganze Note dauert so lange wie 16 Sechzehntelnoten, jede der Sechzehntelnoten so lange wie 1 Sechzehntel. 16 : 1 = 16.

    Richtige Antwort: 16

  3. Aufgabe Nr. 3

    Wie viele Achtelnoten dauern so lange wie eine halbe Note?

    Tipp

    Halbiere Schritt für Schritt: ganze, halbe, Viertel, Achtel, Sechzehntel. Jeder Schritt verdoppelt die Anzahl.

    Lösung
    1. Eine halbe Note dauert so lange wie 8 Sechzehntelnoten, jede der Achtelnoten so lange wie 2 Sechzehntel. 8 : 2 = 4.

    Richtige Antwort: 4

Aufgabe

Eine Note hat ein Fähnchen mehr als eine Achtelnote. Wie lange dauert sie im Vergleich zur Achtelnote?

    Doppelt so lange dauert die Viertelnote, sie hat ein Fähnchen weniger.

    Ein anderes Zeichen heißt eine andere Dauer. Das Fähnchen ändert sie.

    Viermal so lange wie eine Achtel dauert die halbe Note, ganz ohne Fähnchen.
