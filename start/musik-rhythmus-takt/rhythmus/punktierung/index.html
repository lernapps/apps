Ein kleiner Punkt

Die Hälfte kommt dazu

Ein Punkt rechts neben einer Note verlängert sie um die Hälfte ihres eigenen Werts. Eine punktierte halbe Note dauert also eine halbe plus eine Viertel, zusammen drei Viertel. Das gilt auch für Pausen. Die beiden Zeilen im Bild dauern gleich lang:

Eine punktierte halbe Note und eine Viertelnote; die punktierte halbe nimmt drei Viertel der Zeile ein.

Vier Viertelnoten; die ersten drei dauern so lange wie die punktierte halbe Note darüber.

Punktierte Noten
punktierte Notedauert so lange wie
punktierte halbe3 Viertel
punktierte Viertel3 Achtel
punktierte Achtel3 Sechzehntel

Merke

Der Punkt verdoppelt nicht. Er nimmt die Hälfte dazu: halbe plus Viertel, Viertel plus Achtel, Achtel plus Sechzehntel.

Punktierung

Ein Punkt rechts neben einer Note oder Pause; er verlängert sie um die Hälfte ihres Werts.

Beispiel: eine punktierte Viertel in Sechzehnteln

Wie viele Sechzehntelnoten dauern so lange wie eine punktierte Viertelnote?

  1. Eine Viertelnote dauert so lange wie 4 Sechzehntel.
  2. Der Punkt nimmt die Hälfte dazu: die Hälfte von 4 ist 2.
  3. 4 + 2 = 6: Eine punktierte Viertel dauert so lange wie 6 Sechzehntelnoten.

Welche zwei Noten dauern zusammen so lange wie eine punktierte Viertelnote?

    Viertel plus die Hälfte davon, also eine Achtel.

  • zwei Viertelnoten

    Das wäre eine halbe Note. Der Punkt verdoppelt nicht.

    Die Sechzehntel ist nur ein Viertel der Viertel, nicht die Hälfte.

  • eine halbe Note und eine Viertelnote

    Das ist eine punktierte halbe Note, doppelt so lang.

Drei Beispielaufgaben, jede mit ihrer Lösung:

  1. Aufgabe Nr. 1

    Wie viele Sechzehntelnoten dauern so lange wie eine punktierte Achtelnote?

    Tipp

    Rechne zuerst ohne Punkt, dann nimm die Hälfte dazu.

    Lösung
    1. Ohne Punkt: eine Achtelnote dauert so lange wie 2 Sechzehntel, die Hälfte davon ist 1 Sechzehntel. Zusammen sind es 3 Sechzehntelnoten.

    Richtige Antwort: 3

    Richtige Antwort: 6
