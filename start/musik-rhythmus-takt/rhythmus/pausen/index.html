Auch Stille dauert

Auf dieser Seite lernst du, Pausenzeichen zu lesen. Du kennst die Notenwerte von der ganzen bis zur Sechzehntel. In einem Lied gibt es aber auch Stellen, an denen niemand spielt. Schau dir diese Zeile an:

Eine Zeile: Viertelnote, ein Zickzack-Zeichen, Viertelnote, ein Zickzack-Zeichen, gleichmäßig verteilt.

Aufgabe

Die Zeichen stehen gleichmäßig verteilt, wie vier Viertel. Wie lange dauert dann ein Zickzack-Zeichen?

  • so lange wie eine Viertelnote richtige Antwort

    Es steht im selben Abstand wie die Viertelnoten. Es ist eine Viertelpause.

  • so lange wie eine halbe Note

    Dann wäre die Zeile länger als vier Viertel. Das Zeichen nimmt nur den Platz einer Viertel ein.

  • gar nicht, es ist nur eine Verzierung

    Das Zeichen ist eine Pause. Auch Stille hat eine Dauer.

Das Zickzack-Zeichen ist eine Viertelpause. Sie dauert so lange wie eine Viertelnote.

Jede Note hat ihre Pause

Eine Pause ist eine Zeit, in der du nicht spielst. Zu jedem Notenwert gibt es eine Pause, die genauso lange dauert und genauso heißt: ganze Pause, halbe Pause, Viertelpause, Achtelpause, Sechzehntelpause.

Merke

Ganze und halbe Pause sehen fast gleich aus: Die ganze Pause hängt unter der Linie, die halbe liegt auf ihr. Tipp: Die ganze ist „schwerer“ und hängt nach unten. Achtel- und Sechzehntelpause haben einen oder zwei Haken, wie die Noten ein oder zwei Fähnchen.

Fünf Paare aus Note und gleich langer Pause: ganze Note und ganze Pause (ein Balken, der unter der Linie hängt), halbe Note und halbe Pause (ein Balken, der auf der Linie liegt), Viertelnote und Viertelpause (Zickzack), Achtelnote und Achtelpause (schräger Strich mit einem Haken), Sechzehntelnote und Sechzehntelpause (zwei Haken).

Pause

Eine Zeit ohne Ton; jede Pause dauert so lange wie die Note mit gleichem Namen.

Beispiel: eine halbe Pause in Vierteln

Wie viele Viertelnoten dauern so lange wie eine halbe Pause?

  1. Eine halbe Pause dauert so lange wie eine halbe Note.
  2. Eine halbe Note dauert so lange wie zwei Viertelnoten.
  3. Also dauert die halbe Pause so lange wie 2 Viertelnoten.

Aufgabe

Welches Pausenzeichen ist gemeint?

Wähle zu jedem Eintrag das Passende.

Richtige Antwort: ein Balken hängt unter der Linie – ganze Pause; ein Balken liegt auf der Linie – halbe Pause; ein Zickzack – Viertelpause; ein schräger Strich mit zwei Haken – Sechzehntelpause

Hängen oder liegen unterscheidet ganze und halbe Pause; die Zahl der Haken unterscheidet Achtel- und Sechzehntelpause.
