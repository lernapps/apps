Glossar

Die Begriffe dieser App, von A bis Z, jeder mit der Seite, die ihn erklärt.

Hauptschlag

Ein betonter Schlag, den man spürt; im 6/8-Takt auf 1 und 4, je einer pro Dreiergruppe.

Erklärt auf der Seite Der 6/8-Takt

Notenwert

Die Dauer einer Note, abzulesen an ihrem Zeichen; jeder Wert dauert halb so lange wie der nächstgrößere.

Erklärt auf der Seite Notenwerte

Pause

Eine Zeit ohne Ton; jede Pause dauert so lange wie die Note mit gleichem Namen.

Erklärt auf der Seite Pausen

Punktierung

Ein Punkt rechts neben einer Note oder Pause; er verlängert sie um die Hälfte ihres Werts.

Erklärt auf der Seite Punktierung

Taktangabe

Die zwei Zahlen am Anfang; oben die Zahl der Zählzeiten pro Takt, unten der Notenwert einer Zählzeit.

Erklärt auf der Seite Notenwerte im Takt

Taktart

Wie ein Takt aufgebaut ist, benannt nach der Taktangabe, zum Beispiel 3/4-Takt.

Erklärt auf der Seite Notenwerte im Takt

Taktstrich

Ein senkrechter Strich durch die Notenlinie; er beendet einen Takt.

Erklärt auf der Seite Notenwerte im Takt

Triole

Drei gleiche Noten in der Zeit von zweien desselben Werts, markiert mit einer 3.

Erklärt auf der Seite Triolen

zusammengesetzte Taktart

Eine Taktart aus mehreren gleichen Gruppen, zum Beispiel 6/8 aus zwei Gruppen zu drei Achteln.

Erklärt auf der Seite Der 6/8-Takt
