Glossary

The terms of this app, from A to Z, each with the page that explains it.

clipboard

An invisible place where the computer keeps what you copied or cut until you paste it. That is how you can also paste from one program into another.

Explained on the page Using programs

computer system

A device in which a computer works by following a program. A program is an exact set of instructions for the computer. Every computer system has parts you can touch and programs.

Explained on the page Computer systems in everyday life

data

Everything a computer works with, for example numbers, letters, pictures and sounds.

Explained on the page Parts of a computer

hardware

All the parts of a computer system that you can touch, for example the screen, the keyboard and the camera.

Explained on the page Hardware and software

input device

A part that gets data into the computer, for example a camera, a microphone or a keyboard.

Explained on the page Parts of a computer

IPO model

This is how every computer works: Input (data goes in), Process (the processor works with the data in memory), Output (the result comes out).

Explained on the page The IPO model

memory

Holds the data the processor is working on right now. Without power it is empty.

Explained on the page Parts of a computer

output device

A part the computer uses to show, play or print something for you, for example a screen, a loudspeaker or a printer.

Explained on the page Parts of a computer

presentation program

A program for slides that you show during a talk.

Explained on the page Choosing devices and programs

processor

The chip that calculates in a computer and carries out the instructions of programs.

Explained on the page Parts of a computer

software

All the programs of a computer system. On tablets and smartphones they are often called apps. You cannot touch them.

Explained on the page Hardware and software

storage

Keeps data for a long time, even when the device is off, for example photos and apps.

Explained on the page Parts of a computer

word processor

A program for writing and laying out texts.

Explained on the page Choosing devices and programs
