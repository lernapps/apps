Glossar

Die Begriffe dieser App, von A bis Z, jeder mit der Seite, die ihn erklärt.

Arbeitsspeicher

Hält die Daten, an denen der Prozessor gerade arbeitet. Ohne Strom ist er leer.

Erklärt auf der Seite Bestandteile eines Computers

Ausgabegerät

Ein Teil, mit dem der Computer dir etwas zeigt, vorspielt oder druckt, zum Beispiel Bildschirm, Lautsprecher oder Drucker.

Erklärt auf der Seite Bestandteile eines Computers

Daten

Alles, womit ein Computer arbeitet, zum Beispiel Zahlen, Buchstaben, Bilder und Töne.

Erklärt auf der Seite Bestandteile eines Computers

Eingabegerät

Ein Teil, mit dem Daten in den Computer kommen, zum Beispiel Kamera, Mikrofon oder Tastatur.

Erklärt auf der Seite Bestandteile eines Computers

EVA-Prinzip

So arbeitet jeder Computer: Eingabe (Daten kommen hinein), Verarbeitung (der Prozessor arbeitet mit den Daten im Arbeitsspeicher), Ausgabe (das Ergebnis kommt heraus).

Erklärt auf der Seite Das EVA-Prinzip

Festspeicher

Hebt Daten dauerhaft auf, auch wenn das Gerät aus ist, zum Beispiel Fotos und Apps.

Erklärt auf der Seite Bestandteile eines Computers

Hardware

Alle Teile eines Informatiksystems, die du anfassen kannst, zum Beispiel Bildschirm, Tastatur und Kamera.

Erklärt auf der Seite Hardware und Software

Informatiksystem

Ein Gerät, in dem ein Computer nach einem Programm arbeitet. Ein Programm ist eine genaue Anleitung für den Computer. Zu jedem Informatiksystem gehören Teile zum Anfassen und Programme.

Erklärt auf der Seite Informatiksysteme im Alltag

Präsentationsprogramm

Ein Programm für Folien, die man bei einem Vortrag zeigt.

Erklärt auf der Seite Geräte und Programme auswählen

Prozessor

Der Chip, der im Computer rechnet und die Befehle der Programme ausführt.

Erklärt auf der Seite Bestandteile eines Computers

Software

Alle Programme eines Informatiksystems. Auf Tablet und Smartphone heißen sie oft Apps. Anfassen kannst du sie nicht.

Erklärt auf der Seite Hardware und Software

Textverarbeitung

Ein Programm zum Schreiben und Gestalten von Texten.

Erklärt auf der Seite Geräte und Programme auswählen

Zwischenablage

Ein unsichtbarer Platz, an dem der Computer das Kopierte oder Ausgeschnittene bis zum Einfügen aufhebt. So kannst du auch von einem Programm in ein anderes einfügen.

Erklärt auf der Seite Programme bedienen
