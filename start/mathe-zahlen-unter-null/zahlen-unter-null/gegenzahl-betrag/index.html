Wie weit von der Null entfernt?

Jule: Auf der Karte liegt der Schulhof 3 m über dem Meeresspiegel, der Pegel im Hafen auf −3 m.

Karim: Und wie weit ist der Hafenpegel vom Meeresspiegel entfernt? Der Abstand zählt, wie viele Meter es bis zum Meeresspiegel sind, egal in welche Richtung.

Aufgabe

Wie viele Meter sind es vom Meeresspiegel (0 m) bis zum Pegel bei −3 m?

  • 3 m richtige Antwort

    Von 0 bis −3 sind es 3 m. Ein Abstand ist nie negativ.

  • −3 m

    −3 m ist die Lage des Pegels. Gefragt war, wie weit sie entfernt ist, und ein Abstand ist nie negativ.

  • 0 m

    0 m ist der Meeresspiegel selbst, nicht der Abstand zum Pegel.

Der Abstand von der Null wird in Abschnitten gezählt und ist darum nie negativ.

Lösung

    Von 0 bis −3 sind es 3 m. Ein Abstand ist nie negativ.

  • −3 m

  • 0 m

Spiegelbild und Abstand

Wenn du wissen willst, wie weit eine Zahl von der Null entfernt ist und wo ihr Gegenstück liegt, hilft dir die Spiegelung an der Null. Im Bild oben wird 4 an der Null gespiegelt. Spiegelst du eine Zahl an der Null, bekommst du ihre Gegenzahl. Die Gegenzahl von 4 ist −4, die von −4 ist 4. Beide haben den gleichen Abstand von der Null: 4 Abschnitte.

Gegenzahl

Die Gegenzahl einer Zahl liegt auf der anderen Seite der Null mit demselben Abstand. Außer bei 0 hat sie das andere Vorzeichen. Die Gegenzahl von 7 ist −7, die von −2 ist 2, die von 0 ist 0.

Betrag

Der Betrag einer Zahl ist ihr Abstand von der Null. Er ist nie negativ. Man schreibt |−4| = 4 und |4| = 4.

Merke

Betrag und Gegenzahl

Wenn du Betrag und Gegenzahl auseinanderhalten willst, merke dir: Zu einer Zahl und ihrer Gegenzahl gehört derselbe Betrag. Der Betrag einer negativen Zahl ist ihre Gegenzahl: |−4| = 4. Der Betrag einer positiven Zahl bleibt gleich. Der Betrag von 0 ist 0.

Richtige Antwort: Die Aussage stimmt nicht.
