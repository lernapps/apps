Glossar

Die Begriffe dieser App, von A bis Z, jeder mit der Seite, die ihn erklärt.

Entscheidungsbaum

Eine Regel aus Fragen. Jede Antwort führt zur nächsten Frage oder zu einem Ergebnis. Selins Regel ist ein Entscheidungsbaum mit einer Frage und zwei Ästen.

Erklärt auf der Seite Eine Regel aus Beispielen finden

Etikett

Die richtige Antwort zu einem Beispiel, bei uns „Hund“ oder „Katze“.

Erklärt auf der Seite Eine Regel aus Beispielen finden

künstliche Intelligenz (KI)

Computerprogramme, die etwas erkennen, vorschlagen oder übersetzen. Ihr Können haben sie meist aus vielen Beispielen gelernt, statt dass jemand jede Regel programmiert hat.

Erklärt auf der Seite KI im Alltag

maschinelles Lernen

Ein Computer lernt aus Beispieldaten, statt dass jemand jede Regel programmiert.

Erklärt auf der Seite Die Maschine trainieren

Merkmal

Etwas, das man an einem Beispiel beobachten kann, zum Beispiel die Form der Ohren.

Erklärt auf der Seite Eine Regel aus Beispielen finden

nächster Nachbar

Das Beispiel im Beutel, das einem neuen Tier am ähnlichsten ist, also am nächsten, wie dein Sitznachbar. Danach heißt das Verfahren der Maschine.

Erklärt auf der Seite Die Maschine trainieren

Trainingsdaten

Die Beispiele mit Etikett, aus denen gelernt wird: bei uns die Karten im Trainingsbeutel.

Erklärt auf der Seite Eine Regel aus Beispielen finden

Verzerrung (Bias)

Die Trainingsdaten zeigen die Welt einseitig. Das System übernimmt ein Muster, das nur in den Daten gilt.

Erklärt auf der Seite Verzerrte Trainingsdaten
