At the animal shelter: dog or cat?

On the page “Finding a rule from examples” you found a rule yourselves. Now a machine gets the training bag. It should tell the animal shelter: dog or cat? Here you learn how it decides. Then you fill the bag yourself.

How the machine decides

The machine compares the new animal with every card in the bag and counts the features they have in common. The card with the most features in common is the most similar example; if there is a tie, there are several. The machine gives the new animal the label of that card.

Luna is the most similar example. So the machine says: cat. Wrong, Krümel is a dog. The machine counted correctly. The bag is just missing an example like Krümel: a small dog with pointed ears. The machine counts every feature the same. It does not know that the pupils give away the most here, as in Selin's rule.

Sometimes the most similar cat and the most similar dog in the bag are equally similar. Then the machine does not know which label to take.

nearest neighbour

The example in the bag that is most similar to a new animal: the closest one, like the person next to you in class. The machine's method is named after it.

Remember

  • In the card game you find a rule. The machine looks for the most similar example. Both learn only from what is in the bag.
  • If the most similar cat and the most similar dog are equally similar, the machine says: I don't know.

With JavaScript you can put animal cards into the training bag here and choose a new animal. For each card in the bag the machine counts the features in common and gives the new animal the label of the most similar card. At the start the bag holds Luna (cat) and Bruno (dog), and the new animal is Krümel (dog: pointed ears, short snout, small, round pupils). Luna has 3 features in common, Bruno 1: the machine says “cat”. If you add Sammy (dog: pointed ears, short snout, big, round pupils), Sammy also has 3: the machine does not know. If you take Luna out and put Tiger in (cat: pointed ears, short snout, big, narrow pupils), Tiger has 2 and Sammy 3: the machine says “dog”.

Looking back

You have trained a machine. It only got examples with labels and decided from them. This is called machine learning. Only the way it compares is programmed: counting the features in common. Whether dog or cat is decided by the examples in the bag.

What goes into the bag decides what comes out. With good examples in the bag, the machine can now help the animal shelter.
