Glossar

Die Begriffe dieser App, von A bis Z, jeder mit der Seite, die ihn erklärt.

Bassschlüssel

Der Notenschlüssel, der das kleine f auf die 4. Linie legt; auch F-Schlüssel genannt.

Erklärt auf der Seite Bassschlüssel

Dreiklang

Drei Töne übereinander, Grundton, Terz und Quinte; zwei Terzen geschichtet.

Erklärt auf der Seite Dreiklänge aufbauen

Dur-Dreiklang

Ein Dreiklang mit großer Terz unten und kleiner Terz oben.

Erklärt auf der Seite Dur und Moll in Kurzschrift

Ganztonschritt

Zwei Halbtonschritte zusammen, zum Beispiel von c über die schwarze Taste zu d.

Erklärt auf der Seite Halbtonschritte

Grundton

Der unterste Ton eines Dreiklangs, wenn die Töne als Terzen übereinander stehen; nach ihm heißt der Dreiklang.

Erklärt auf der Seite Dreiklänge aufbauen

Halbtonschritt

Der kleinste Schritt auf der Klaviatur, von einer Taste zur allernächsten, schwarz oder weiß.

Erklärt auf der Seite Halbtonschritte

Hilfslinie

Eine kurze Linie über oder unter dem Notensystem, für einen Ton, der nicht mehr ins System passt.

Erklärt auf der Seite Noten benennen

Intervall

Der Abstand zwischen zwei Tönen, benannt nach der Zahl der Stammtöne, beide Töne mitgezählt.

Erklärt auf der Seite Intervalle grob bestimmen

Kurzschrift

Ein Dreiklang mit dem Namen seines Grundtons, groß geschrieben für Dur (C), klein für Moll (c).

Erklärt auf der Seite Dur und Moll in Kurzschrift

Moll-Dreiklang

Ein Dreiklang mit kleiner Terz unten und großer Terz oben.

Erklärt auf der Seite Dur und Moll in Kurzschrift

Notensystem

Fünf waagrechte Linien, auf denen und zwischen denen Noten stehen. Oben bedeutet hoch, unten tief.

Erklärt auf der Seite Notensystem und Violinschlüssel

Oktave

Der Abstand von einem Ton zum nächsten Ton mit gleichem Namen, acht Stammtöne weit.

Erklärt auf der Seite Oktavlagen

Stammton

Einer der sieben Töne c, d, e, f, g, a, h, die Töne der weißen Tasten.

Erklärt auf der Seite Notensystem und Violinschlüssel

Violinschlüssel

Der Notenschlüssel, der das g¹ auf die 2. Linie legt; auch G-Schlüssel genannt.

Erklärt auf der Seite Notensystem und Violinschlüssel

Vorzeichen

Kreuz (♯), b (♭) oder Auflösungszeichen (♮) vor einer Note; es erhöht, erniedrigt oder stellt den Stammton wieder her. Genau genommen heißt das Zeichen direkt vor einer Note Versetzungszeichen.

Erklärt auf der Seite Vorzeichen
