Wie weit ist es von g¹ nach h¹?

Auf dieser Seite lernst du, den Abstand zwischen zwei Tönen abzuzählen und ihm seinen Namen zu geben. Du kennst schon Schritte und Sprünge. Probier zuerst:

Ein Notensystem mit zwei Noten nacheinander, g¹ auf der 2. Linie und h¹ auf der 3. Linie.

Aufgabe

Wie viele Stammtöne zählst du von g¹ bis h¹, wenn du beide Töne mitzählst?

Richtige Antwort: 3

g¹, a¹, h¹: drei Stammtöne. Dieser Abstand heißt Terz, nach der Zahl drei.

Stammtöne abzählen, beide mitgezählt

Den Abstand zwischen zwei Tönen nennt man Intervall. Bei der Grobbestimmung zählst du die Stammtöne vom unteren bis zum oberen Ton, beide mitgezählt. Die Zahl gibt dem Intervall seinen Namen, nach lateinischen Zahlwörtern. Vorzeichen spielen dabei keine Rolle: c bis e und c bis es sind beide eine Terz.

Intervall

Der Abstand zwischen zwei Tönen, benannt nach der Zahl der Stammtöne, beide Töne mitgezählt.

Ein Notensystem mit acht Noten von c¹ bis c², nummeriert 1 bis 8: c¹ (1), d¹ (2), e¹ (3), f¹ (4), g¹ (5), a¹ (6), h¹ (7), c² (8). Von c¹ zu einem Ton ist das Intervall so groß wie seine Zahl.

Merke

Zähl immer den Startton mit. Im Notenbild hilft dir das: Von einer Linie zur nächsten Linie ist eine Terz, von einer Linie zum Zwischenraum direkt darüber eine Sekunde, von einer Linie zur übernächsten Linie eine Quinte.

Beispiel: von d¹ bis a¹

Welches Intervall liegt zwischen d¹ und a¹?

  1. Zähl die Stammtöne aufwärts, d¹ mitgezählt: d¹ (1), e¹ (2), f¹ (3), g¹ (4), a¹ (5).
  2. Fünf Stammtöne: Das Intervall ist eine Quinte.
  3. Im Notenbild: d¹ hängt unter der 1. Linie, a¹ steht im 2. Zwischenraum. Das sind zwei Zwischenräume weiter, so wie von einer Linie zur übernächsten Linie.

Übung

Aufgabe

Welches Intervall zeigt das Notenbild?

Wähle zu jedem Eintrag das Passende.

Richtige Antwort: beide Noten auf demselben Platz – Prime; von einer Linie zum Zwischenraum direkt darüber – Sekunde; von einer Linie zur nächsten Linie – Terz; von einer Linie zur übernächsten Linie – Quinte

Linie zur nächsten Linie überspringt einen Zwischenraum: drei Stammtöne, eine Terz. Noch eine Linie weiter sind es fünf, eine Quinte.

  1. Aufgabe Nr. 1

    Wie viele Stammtöne zählst du von e aufwärts bis g, beide mitgezählt?

    Tipp

    Sag die Stammtöne der Reihe nach auf und zähl mit: c, d, e, f, g, a, h, dann c¹ und so weiter.

    Lösung

    Richtige Antwort: 3
