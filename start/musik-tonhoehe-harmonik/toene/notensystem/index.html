Hoch und tief auf dem Papier

Auf dieser Seite lernst du, wie das Notensystem gebaut ist und was der Violinschlüssel darin festlegt. Du weißt schon, dass Töne hoch oder tief klingen. Probier, wie man das auf dem Papier sieht:

Ein Notensystem mit zwei Noten. Note 1 steht im untersten Zwischenraum, Note 2 auf der 4. Linie.

Aufgabe

Welche der beiden Noten klingt höher?

  • Note 2 richtige Antwort

    Note 2 steht weiter oben im System. Je höher eine Note steht, desto höher klingt sie.

  • Note 1

    Note 1 steht weiter unten im System, sie klingt tiefer.

  • Beide gleich hoch

    Gleich hoch klingen zwei Noten nur, wenn sie auf demselben Platz stehen. Hier stehen sie verschieden.

Im Notensystem bedeutet oben hoch und unten tief, wie auf einer Leiter.

Fünf Linien und ein Schlüssel

Das Notensystem hat fünf Linien. Zwischen ihnen liegen vier Zwischenräume. Linien und Zwischenräume zählt man immer von unten: Die unterste Linie ist die 1. Linie. Eine Note steht entweder auf einer Linie, dann geht die Linie durch die Note, oder in einem Zwischenraum.

Notensystem

Fünf waagrechte Linien, auf denen und zwischen denen Noten stehen. Oben bedeutet hoch, unten tief.

Ohne Schlüssel weißt du nur, welche Note höher ist, aber nicht, wie sie heißt. Der Violinschlüssel löst das. Seine Schnecke kreist um die 2. Linie und legt fest: Auf der 2. Linie steht das g¹. Darum heißt er auch G-Schlüssel.

Ein Notensystem mit Violinschlüssel, die Linien von unten nummeriert. Die 2. Linie ist markiert. Die Schnecke des Schlüssels kreist um diese Linie. Auf ihr steht eine Note: g¹.

Die Töne der weißen Tasten heißen Stammtöne: c, d, e, f, g, a, h, danach wieder c. Jeder Schritt im System, von der Linie in den Zwischenraum oder vom Zwischenraum auf die Linie, führt zum nächsten Stammton.

Stammton

Einer der sieben Töne c, d, e, f, g, a, h, die Töne der weißen Tasten.

Violinschlüssel

Der Notenschlüssel, der das g¹ auf die 2. Linie legt; auch G-Schlüssel genannt.

Beispiel: der Nachbar von g¹

Welcher Ton steht im Zwischenraum direkt über der 2. Linie?

  1. Auf der 2. Linie steht g¹, das legt der Violinschlüssel fest.
  2. Ein Schritt höher, in den Zwischenraum darüber, ist der nächste Stammton nach g: a.
  3. Der Ton heißt a¹.

Aufgabe

Welche Linie legt der Violinschlüssel fest?

  • Die 2. Linie, auf ihr steht g¹ richtige Antwort

    Die Schnecke des Violinschlüssels kreist um die 2. Linie. Dort steht g¹.

  • Die 1. Linie, auf ihr steht g¹

    Die 1. Linie ist die unterste, eine Linie unter der Linie des Schlüssels.

  • Die 3. Linie, auf ihr steht g¹

    Die 3. Linie ist die mittlere Linie. Dort steht h¹, über dem g¹.

  • Die 4. Linie, auf ihr steht g¹

    Die 4. Linie liegt weit oben im System, nicht dort, wo die Schnecke kreist.
