Die schwarzen Tasten

Auf dieser Seite lernst du, Töne mit Kreuz, b und Auflösungszeichen zu lesen und zu schreiben. Bisher hatten alle Noten Namen von weißen Tasten. Probier, wie die markierte schwarze Taste heißen könnte:

Eine Klaviatur von c¹ bis h¹. Gelb markiert ist die schwarze Taste zwischen f¹ und g¹.

Aufgabe

Die markierte Taste liegt einen Halbtonschritt über f¹. Wie könnte sie heißen?

  • fis¹ richtige Antwort

    An den Namen f wird -is angehängt: fis heißt „f, einen Halbtonschritt höher“.

  • f¹

    Das f¹ ist die weiße Taste links daneben, einen Halbtonschritt tiefer.

  • g¹

    Das g¹ ist die weiße Taste rechts daneben.

Schwarze Tasten bekommen den Namen einer weißen Nachbartaste mit einer Endung. Über f liegt fis.

Kreuz, b und Auflösungszeichen

Ein Zeichen vor einer Note verändert den Ton um einen Halbtonschritt. Das Kreuz ♯ erhöht: An den Namen kommt -is (f wird fis, c wird cis). Das b ♭ erniedrigt: An den Namen kommt -es (d wird des, g wird ges). Drei Namen sind kürzer: e wird es, a wird as, und h wird b.

Eine Klaviatur von c¹ bis h¹. Die schwarzen Tasten heißen mit Kreuz cis¹, dis¹, fis¹, gis¹, ais¹.

Dieselbe Klaviatur. Mit b heißen die schwarzen Tasten des¹, es¹, ges¹, as¹, b¹.

Jede schwarze Taste hat also zwei Namen: fis und ges klingen gleich. Welcher Name gilt, sagt das Zeichen vor der Note. Musik ist in Takte eingeteilt; senkrechte Striche durch das System, die Taktstriche, trennen sie. Ein Zeichen vor einer Note gilt bis zum nächsten Taktstrich. Das Auflösungszeichen ♮ hebt es vorher auf: Der Ton heißt dann wieder wie der Stammton.

Vorzeichen

Kreuz (♯), b (♭) oder Auflösungszeichen (♮) vor einer Note; es erhöht, erniedrigt oder stellt den Stammton wieder her. Genau genommen heißt das Zeichen direkt vor einer Note Versetzungszeichen.

Merke

Schau vor dem Benennen immer zuerst links neben die Note. Ein vergessenes Zeichen ist der häufigste Fehler: f und fis liegen auf demselben Platz im System.

Beispiel: eine Note mit b

Im Violinschlüssel steht auf der 3. Linie eine Note mit ♭ davor. Wie heißt sie?

  1. Ohne Zeichen: Von g¹ auf der 2. Linie zwei Schritte hoch, die 3. Linie ist h¹.
  2. Das ♭ erniedrigt um einen Halbtonschritt.
  3. h mit ♭ hat einen kurzen Namen: Der Ton heißt b¹.

Aufgabe

In einem Takt steht vor f¹ ein ♯. Etwas später, im selben Takt, steht noch einmal f¹ ohne Zeichen. Wie heißt der zweite Ton?

  • fis¹ richtige Antwort

    Das Kreuz gilt bis zum nächsten Taktstrich, also auch für das zweite f¹ im selben Takt.

  • f¹

    So wäre es erst nach dem Taktstrich oder mit einem Auflösungszeichen ♮ davor.

  • ges¹

    Das ges¹ klingt wie fis¹, wird aber mit ♭ vor g geschrieben. Hier steht ein ♯ vor f.

Aufgabe

Im Takt steht zuerst b¹ (h¹ mit ♭), dann h¹ mit ♮ davor. Wie heißt der zweite Ton?

  • h¹ richtige Antwort

    Das ♮ hebt das ♭ auf. Der Ton heißt wieder wie der Stammton, h¹.

  • b¹

    Ohne das ♮ wäre es b¹, weil das ♭ bis zum Taktstrich gilt. Das ♮ hebt es aber auf.

  • his¹

    Das ♮ erhöht nicht, es stellt nur den Stammton wieder her.

Das Auflösungszeichen ♮ macht ein Kreuz oder b vor dem Taktstrich rückgängig.
