Zweimal c

Auf dieser Seite lernst du, Töne mit gleichem Namen auseinanderzuhalten und genau zu sagen, welches c gemeint ist. Du kennst die Klaviatur schon. Schau dir die beiden markierten Tasten an:

Eine Klaviatur mit zwei Oktaven. Gelb markiert sind zwei weiße Tasten links von zwei schwarzen Tasten: die erste ganz links, die zweite beim nächsten c: acht weiße Tasten, beide mitgezählt.

Aufgabe

Beide markierten Tasten sind ein c. Was stimmt?

  • Die rechte klingt höher als die linke. richtige Antwort

    Auf der Klaviatur klingen Tasten weiter rechts höher. Gleicher Name heißt nicht gleiche Höhe.

  • Beide klingen genau gleich hoch.

    Gleich hoch klingt nur dieselbe Taste. Die beiden c liegen eine Oktave auseinander, acht weiße Tasten, beide mitgezählt.

  • Die linke klingt höher als die rechte.

    Auf der Klaviatur wird es nach links tiefer, nicht höher.

Die beiden c klingen verwandt, fast wie derselbe Ton, aber das rechte klingt höher. Der Abstand zwischen ihnen heißt Oktave.

Jede Oktave beginnt mit c

Von einem c bis zum nächsten c sind es acht weiße Tasten, das erste c mitgezählt: c, d, e, f, g, a, h, c. Diesen Abstand nennt man Oktave (lateinisch „die Achte“). Weil sich die Namen jede Oktave wiederholen, bekommt jede Oktave eine eigene Schreibweise. Eine neue Oktave beginnt immer mit c.

Oktave

Der Abstand von einem Ton zum nächsten Ton mit gleichem Namen, acht Stammtöne weit.

Eine Klaviatur mit zwei Oktaven. Die linke Oktave heißt kleine Oktave, ihre Tasten c, d, e, f, g, a, h. Die rechte heißt eingestrichene Oktave, ihre Tasten c¹, d¹, e¹, f¹, g¹, a¹, h¹.

Die Oktavlagen von tief nach hoch
OktaveTöne
große OktaveC bis H, groß geschrieben
kleine Oktavec bis h, klein geschrieben
eingestrichene Oktavec¹ bis h¹, mit ¹
zweigestrichene Oktavec² bis h², mit ²

Merke

Die Oktave wechselt beim c, nicht beim a. Das h ist der letzte Ton einer Oktave: Rechts neben h kommt c¹, rechts neben h¹ kommt c². Das c¹ liegt in der Mitte der Klaviatur.

Beispiel: eine Oktave über a

Wie heißt der Ton eine Oktave über a?

  1. Das a ohne Strich liegt in der kleinen Oktave.
  2. Zähl acht weiße Tasten nach rechts, das a mitgezählt: a, h, c¹, d¹, e¹, f¹, g¹, a¹.
  3. Beim c¹ hat die eingestrichene Oktave begonnen, darum heißt das Ziel a¹.
