Chemische Reaktionen

Du erkennst chemische Reaktionen, unterscheidest sie von Zustandsänderungen, erklärst die Massenerhaltung und stellst einfache Reaktionsgleichungen auf.

  1. Woran du eine Reaktion erkennst Farbe, Gas, Wärme oder Licht können auf eine chemische Reaktion hinweisen. Sicher ist nur ein neuer Stoff.
  2. Reaktion oder Zustandsänderung? Bei einer Zustandsänderung bleibt der Stoff derselbe, bei einer chemischen Reaktion entsteht ein neuer.
  3. Die Masse bleibt gleich Bei einer Reaktion bleibt die Gesamtmasse gleich. Das zeigt ein Versuch mit der Waage, und die Atome erklären es.
  4. Reaktionsgleichungen Eine Reaktionsgleichung zeigt, welche Stoffe reagieren. Auf beiden Seiten müssen gleich viele Atome stehen.
