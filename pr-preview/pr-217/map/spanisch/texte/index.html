Lücke

Klasse 5/6

  • Fragen zu einem Text stellen und beantworten (¿Quién? ¿Qué? ¿Dónde? ¿Cuándo? ¿Por qué?) (Lücke, noch keine App)
  • Alltagstexten wie Speisekarten, Fahrplänen, Prospekten und Schildern gezielt Informationen entnehmen (Lücke, noch keine App)
  • Einer kurzen Filmszene entnehmen, wer mitspielt, wo sie spielt und was passiert (Lücke, noch keine App)
  • Ein spanisches Lied oder ein kurzes Gedicht verstehen und vortragen (Lücke, noch keine App)
  • Sagen, wie ein Lied, ein Text oder ein Film auf mich wirkt und welche Gefühle er bei mir auslöst (Lücke, noch keine App)
  • Eine kurze Nachricht schreiben, zum Beispiel eine Verabredung oder eine Absage im Chat (Lücke, noch keine App)
  • Einen persönlichen Brief oder eine E-Mail mit passender Anrede und passendem Gruß schreiben (Querida Ana: … Un abrazo) (Lücke, noch keine App)
  • Einen kurzen Dialog oder eine Spielszene schreiben (Lücke, noch keine App)
  • Einen Tagebucheintrag über meinen Tag oder ein Erlebnis schreiben (Lücke, noch keine App)
  • Zu einer Bildergeschichte erzählen oder aufschreiben, was passiert (Lücke, noch keine App)
  • Eine kurze Geschichte oder ein Erlebnis mit Anfang, Mitte und Ende aufschreiben (Lücke, noch keine App)
  • Den Inhalt einer Geschichte in eigenen Worten nacherzählen (Lücke, noch keine App)
  • Das Wichtigste eines kurzen Textes in wenigen Sätzen zusammenfassen (Lücke, noch keine App)
  • Einen kurzen Vortrag zu einem Thema mit einem Stichwortzettel gliedern und halten (Lücke, noch keine App)

Klasse 7/8

  • Sachtexte und erzählende Texte unterscheiden und typische Merkmale nennen (Lücke, noch keine App)
  • Einem kurzen Zeitungsartikel entnehmen, was wann, wo und warum passiert ist (Lücke, noch keine App)
  • Einem Interview entnehmen, was die befragte Person über sich erzählt und was sie meint (Lücke, noch keine App)
  • Erkennen, wie eine Anzeige oder ein Werbetext mit Bild und Sprache überzeugen will (Lücke, noch keine App)
  • Eine vereinfachte Lektüre oder einen Auszug aus einem Jugendroman lesen und die Handlung verstehen (Lücke, noch keine App)
  • Einen Text in Abschnitte gliedern und jedem Abschnitt eine Überschrift geben (Lücke, noch keine App)
  • Einen kurzen Bericht über ein Ereignis schreiben: wer, was, wann und wo (Lücke, noch keine App)
  • Eine Inhaltsangabe (resumen) schreiben: Thema, Hauptpersonen und wichtigste Handlung im Präsens (Lücke, noch keine App)
  • Eine Geschichte fortsetzen oder ein anderes Ende dafür schreiben (Lücke, noch keine App)
  • Eine Geschichte aus der Sicht einer anderen Figur erzählen (Lücke, noch keine App)
  • Einen Text in eine andere Textsorte umschreiben, zum Beispiel eine Geschichte in einen Dialog (Lücke, noch keine App)
  • In einer kurzen Stellungnahme meine Meinung zu einem Text oder Thema schreiben und mit Gründen stützen (Lücke, noch keine App)
  • Einen Blogbeitrag oder einen Kommentar in einem Online-Forum schreiben (Lücke, noch keine App)

Klasse 9/10

  • Ein einfaches Diagramm oder eine Statistik beschreiben und sagen, was sie zeigt (Lücke, noch keine App)
  • Auffällige sprachliche Mittel in einem Text erkennen, zum Beispiel Wiederholungen, Vergleiche oder Fragen an die Leser, und sagen, was sie bewirken (Lücke, noch keine App)
  • Eine Figur aus einem Text beschreiben und ihr Verhalten mit Stellen aus dem Text erklären (Lücke, noch keine App)
  • Eine förmliche E-Mail schreiben, zum Beispiel eine Anfrage oder eine Reservierung (Estimados señores: …) (Lücke, noch keine App)
