The map and the apps

  1. The map splits a subject into building blocks. Each has a short name and a sentence: “I can …”.
  2. Each app says which building blocks its pages practise.
  3. On the map, such a building block is blue. Dashed means: an app is still missing here.

Build an app for a gap

To be honest

The map is a method of our own

There is no ready-made template that shows how the knowledge of a subject belongs together. So we came up with a method of our own.

  • Curricula set the order in which things are taught. Each German state has its own. They show only in part how the knowledge belongs together logically.
  • The KMK educational standards describe what children should be able to do. But they do not exist for every subject.

So we sort the knowledge by how it belongs together logically: what builds on what? Within that, each state gets its own order. Choose a curriculum on a map to see its grades.

Something is missing or in the wrong place? Let us know (GitHub issue, needs a GitHub account)

How the map is built

Click a box in the picture to get the term explained.

All terms as a list

Subject

A school subject. Each subject has a learning map of its own.

Example: Mathematics, physics, music.

In the picture: A subject has several strands. Its strands and building blocks come from a source.

Strand

A part of the subject that runs over several school years. What is in it builds on itself.

Example: Algebra, geometry, probability.

In the picture: A strand has several building blocks. An app stays in one strand.

Building block

One thing a child can learn, with a short name and a sentence “I can …”. Each building block belongs to exactly one strand.

Example: “I can calculate the percentage value.”

In the picture: A building block builds on other building blocks. A curriculum places it in grades. Pages of apps practise it.

builds on

Building block B needs building block A first. This also holds across strands. Together they make the learning path. There is no fixed order within a strand.

Example: Exponential growth (strand Functions) builds on percentages (strand Arithmetic).

In the picture: The arrow leads from one building block to another.

Step

Where a building block stands in the chain of “builds on” within its grade band. Step 1 has no prerequisite of the same grade band. Otherwise a building block stands one step below its deepest prerequisite of the same grade band. Everything in the same step is independent of each other; everything above comes first.

Example: Percentage (grade 7/8) builds on fractions (grade 5/6) and on the rule of three (grade 7/8, step 1). So it stands in grade 7/8, step 2.

In the picture: The step is not written for a building block, it is computed from “builds on” and the grade band. It has no box of its own in the picture.

Grade band

Roughly in which two school years a building block is taught: grade 5/6, 7/8 or 9/10. Every building block has one. The map shows it when no curriculum is chosen or a curriculum does not place the building block.

Example: Tree diagram: grade band 7/8.

In the picture: The grade band is part of the building block. It has no box of its own in the picture.

Curriculum and placement

A curriculum holds for one German state and one type of school. The placement says in which grade this curriculum teaches a building block. That can be several grades. We capture the curricula one by one.

Example: Tree diagram: curriculum Hesse, grammar school: grades 7 and 10.

In the picture: A curriculum places building blocks in grades.

Source

Where the strands and building blocks of a subject come from. The source says how binding the map is.

Example: KMK educational standards in mathematics (2022). For subjects without standards, a subject association or one state's curriculum.

In the picture: A subject comes from a source.

App

A learning app on lernapps.net. It stays in one strand and grows along the learning path with new versions.

Example: An app “Probability 5–10”.

In the picture: An app stays in one strand and has several pages.

Page

A page of an app. It practises one or more building blocks. That is how the map knows which building blocks are practised and where the gaps are.

Example: The page “Percentage value” of an app on percentages.

In the picture: A page belongs to an app and practises one or more building blocks.

Three rules

  1. Each building block belongs to exactly one strand.
  2. Each app stays in one strand and grows with new versions along the arrows “builds on”.
  3. When a building block is taught is set by the curriculum. Without a curriculum, the grade band holds.
