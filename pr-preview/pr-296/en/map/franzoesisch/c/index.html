Learning map French by grade and chain

?How to read the map

The rows go by grade: first 5/6, then 7/8, then 9/10. Within a grade, a building block stands one step below its deepest prerequisite of the same grade. So everything a building block needs stands above it. Everything in the same step is independent of each other.

How to read the map

Strand · a column
A part of the subject that runs over several school years.
Building block · a box
One thing a child can learn: “I can …”.
Step · a row
Where a building block stands in its grade in the chain of “builds on”. Everything in the same step is independent of each other; everything above comes first.
App · the colour
Blue means covered: an app practises the building block. Dashed means gap: no app practises it yet.
