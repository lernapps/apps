Die Kette

Wähle einen Baustein in der Karte. Dann siehst du hier seine Kette.

Klicke auf einen Baustein. Dann siehst du, worauf er aufbaut und was auf ihm aufbaut, Schritt für Schritt.

So liest du die Karte

Strang · eine Spalte
Ein Teilgebiet des Fachs, das sich über mehrere Schuljahre zieht.
Baustein · ein Kästchen
Eine Sache, die ein Kind lernen kann: „Ich kann …“.
Schritt · eine Zeile
Wo ein Baustein in seiner Klasse in der Kette „baut auf“ steht. Alles im selben Schritt ist voneinander unabhängig; alles darüber kommt vorher.
App · die Farbe
Blau heißt abgedeckt: Eine App übt den Baustein. Gestrichelt heißt Lücke: Noch keine App übt ihn.
