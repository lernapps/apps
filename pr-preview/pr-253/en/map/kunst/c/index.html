How to read the map

Strand · a column
A part of the subject that runs over several school years.
Building block · a box
One thing a child can learn: “I can …”.
Step · a row
How far down a building block stands in the chain of “builds on”. It says nothing about grades.
App · the colour
Blue means covered: an app practises the building block. Dashed means gap: no app practises it yet.
